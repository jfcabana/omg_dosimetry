# This folder is intended for testing.

As a first step, I am going to follow this [guide](https://realpython.com/python-testing/#testing-your-code), using [unittest](https://docs.python.org/3/library/unittest.html) library.

## How to perform a test

From the root directory of the project, run the following code:

```
python -W ignore:ResourceWarning -m unittest discover -s tests -v
```
